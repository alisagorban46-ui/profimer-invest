# ПРОФИМЕР [ ФЛИППИНГ ] — лендинг

## Запуск
Просто откройте `index.html` в браузере (двойной клик) — сайт полностью статический,
сервер не нужен. Все три файла (`index.html`, `style.css`, `script.js`) должны лежать
в одной папке.

## Важные технические примечания

1. **Цвет #57A396** — рабочее значение, определённое визуально по пикселям логотипа
   направления «флиппинг» в брендбуке (в самом PDF в текстовых полях для этого
   образца продублированы HEX/RGB синего цвета — технически это опечатка в
   исходном файле). Перед продакшеном уточните точный HEX у автора брендбука.

2. **Шрифт CHAVA** (декоративный, для мелких акцентов) в брендбуке — не является
   общедоступным веб-шрифтом, подключить напрямую с Google Fonts нельзя. Сейчас
   вместо него подключён близкий по пиксельному духу `Press Start 2P` (Google
   Fonts) — используется только для пяти чипов в блоке «О команде». Как только
   у вас будут файлы настоящего CHAVA (.woff2), замените `font-family: var(--font-accent)`
   в `style.css` на реальный `@font-face`.

3. **Фото** — в hero-секции сейчас декоративная заглушка (тёмный паттерн + подпись
   в скобках), а не фото. Чтобы поставить своё изображение: в `index.html` замените
   `<div class="photo-placeholder">...</div>` на `<img src="ваше-фото.jpg" alt="">`
   внутри `.hero-photo`, в `style.css` эта обёртка уже имеет `position: absolute; inset:0`
   — достаточно будет добавить `.hero-photo img { width:100%; height:100%; object-fit:cover; }`.

4. **Калькулятор и финальная форма** сейчас ничего никуда не отправляют (нет бэкенда) —
   в `script.js` в местах с комментарием «Здесь в реальном проекте — отправка…»
   нужно подставить реальный запрос к вашей CRM/почте.

5. **Контакты в футере** не указаны намеренно — в материалах не было реального
   телефона/почты для этого направления, придумывать не стал.
